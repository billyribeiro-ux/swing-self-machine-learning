# Assumptions

These assumptions require evidence and may change through a dated decision.

- Daily data is the correct first resolution for the swing engine.
- A next-open entry is a conservative and reproducible starter assumption.
- Fixed holding-period exits are useful for initial discovery before adding stops and trailing exits.
- RSI may contain contextual information for at least some tickers or regimes, but it is only one feature family and baseline.
- Cross-instrument relationships, breadth, sector behavior, inverse/leveraged ETF behavior, and regime features may improve swing attribution, but their value must be validated out of sample.
- Standard RSI settings may act as crowd-attention markers, but the causal institutional story is not yet proven.
- Large liquid stocks and ETFs are an appropriate initial seed universe, but current-universe historical tests may contain survivorship bias.
- Free data can bootstrap software development, but production-grade validation will require audited data quality.
- The stated 98.5% accuracy requires a precise, reproducible definition before it can be evaluated.
